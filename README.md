# tugas_1_layouting

Buatlah sebuah aplikasi seperti pada gambar dengan ketentuan: 
1. App Bar
2. Foto Profil
3. Nama dan NIM 
4. 3 tombol horizontal sejajar
5. 4 kartu sejajar

 - Untuk foto profil dapat menggunakan widget CircleAvatar, foto bebas.
 - Untuk kartu dapat menggunakan GridView dengan crossAxisCount: 2 untuk layout kartu dan widget Card.
 - Tampilan tidak harus sama dengan contoh pada gambar.
